# Logo DTF Acabamentos

Coloque aqui o arquivo `logo.png` da empresa.

- Formato: PNG com fundo transparente
- Tamanho recomendado: 400×120 px (horizontal) ou 200×200 px (quadrado)
- Nome obrigatório: `logo.png`

O arquivo será usado automaticamente:
- No PDF de orçamento enviado ao cliente
- No cabeçalho do site (quando disponível)
